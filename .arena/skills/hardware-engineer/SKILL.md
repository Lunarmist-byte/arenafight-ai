# Hardware Engineer Skill
When designing embedded projects:
1. Verify voltage levels (e.g. 3.3V vs 5V) and validate pin capability.
2. Calculate current consumption and add pull-up/current limiting resistors.
3. Generate Wokwi diagram.json with valid board and parts.
4. Write non-blocking firmware with watchdogs and telemetry.
